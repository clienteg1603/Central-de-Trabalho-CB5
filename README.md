# Central de Trabalho CB5 — arquivos de atualização

Repositório público usado somente para publicar os pacotes e manifestos da Central de Trabalho.

- `updates/stable.json`: canal Estável
- `updates/test.json`: canal Teste
- `updates/packages/`: pacotes ZIP assinados por SHA-256 nos manifestos

O programa acessa apenas URLs HTTPS públicas e não armazena credenciais do GitHub.
